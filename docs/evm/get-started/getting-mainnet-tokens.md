---
title: Getting and exchanging Mainnet tokens
---

The native coin on Etherlink<!--TX--> has the symbol XTZ, similar to but separate from the [tez tokens on Tezos layer 1](https://docs.tezos.com/architecture/tokens).
For more information about that token and the tokens that are available on Etherlink EVM<!--TEVM-->, see [Tokens](/evm/developing/tokens).

## Getting Mainnet XTZ

To get Etherlink EVM<!--TEVM--> Mainnet XTZ, you can:

- Buy or swap for it on [exchanges](/evm/tools/exchanges)

- Use [on-ramps](/evm/tools/onramps) to buy it with fiat currency

:::note

On exchanges, be sure that you are getting Etherlink EVM<!--TEVM--> XTZ and not Tezos layer 1 XTZ or wrapped XTZ (WXTZ) on another platform.
If you have XTZ on a different platform, you can bridge it to Etherlink EVM<!--TEVM--> XTZ as described in [Bridging](/evm/bridging/).

:::

## Exchanging Mainnet XTZ

When you are ready to sell tokens on Etherlink<!--TX--> Mainnet, you have these options:

- Swap or sell Etherlink EVM<!--TEVM--> XTZ on [exchanges](/evm/tools/exchanges)

- Use [off-ramps](/evm/tools/onramps) to sell XTZ for fiat currency

- Bridge XTZ to other chains as described in [Bridging](/evm/bridging/)
